# Bedre Mørkhet for Utenfilter.no
Fiks av mørkemodus for Uten Filter.


## Hvordan bruke dette?
Bruk en nettleserutvidelse som lar deg bruke egendefinert CSS på nettsteder. Selv bruker jeg [Stylus](https://add0n.com/stylus.html).  
Naviger deg til ["Releases"](https://github.com/HappinessPK/utenfilter.no/releases) og last ned "utenfilter-stylus.json" for Stylus eller "utenfilter.css" for andre utvidelser.  

## Problemer?
Funnet en feil? Nettsiden har blitt oppdatert? Andre henvedelser relatert til disse modifikasjonene?  
Rappoter det med en ny ["Issue"](https://github.com/HappinessPK/utenfilter.no/issues/new), så tar jeg en titt når jeg har tid.

## English?
Just use a translating service, you would have to translate the webpage to read it to begin with.
