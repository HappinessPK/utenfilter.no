# Better darkmode for Utenfilter.no
Some improvements on the norwegian news page "Uten Filter".


## How to apply?
Use an extension for your browser that enables custom css for websites. I personally use [Stylus](https://add0n.com/stylus.html).  
If you are using Stylus, just download the latest release and import it using the style manager.  
For other extensions, just copy the contents of [userstyle.css](https://github.com/HappinessPK/utenfilter.no/blob/main/userstyle.css) and paste it within the editor.
